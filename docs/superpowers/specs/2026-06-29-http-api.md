# Phase 7 — HTTP API Design Spec

**Date:** 2026-06-29
**Scope:** New `api/` package; minor additions to `policyloop/src/index.ts` exports

---

## Problem

The execution pipeline (`runPolicyCycle`, signer, Walrus) is now production-grade but only accessible via the daemon process. Phase 7 exposes it as a narrow HTTP API so external systems can trigger a policy cycle on demand.

---

## Goals

- `POST /policies/:id/run-cycle` — trigger one cycle for a given policy ID
- `GET /health` — liveness check
- `GET /version` — package version
- Static API key auth (`X-Api-Key` header) on all routes
- `API_ALLOWED_POLICY_IDS` allowlist guard on `POST /policies/:id/run-cycle`
- Thin wrapper — the route handler calls `runPolicyCycle` and returns its result as JSON

---

## What is NOT in scope

- Multi-policy endpoints
- Admin endpoints (pause/resume/revoke policy)
- JWT or OAuth auth
- Rate limiting
- Request body on POST (all config comes from env)
- TLS termination (handled by reverse proxy)
- Daemon-mode interval config (this is on-demand, not periodic)

---

## Package structure

New standalone package at `nexus/api/`:

```
api/
  package.json
  tsconfig.json
  src/
    config.ts          — read + validate API-specific env vars
    server.ts          — buildServer() factory with all routes
    server.test.ts     — tests via fastify.inject()
  bin/
    server.ts          — startup entry point
```

`api/` follows the same conventions as existing packages: ESM (`"type": "module"`), `NodeNext` module resolution, `tsx` for dev, `vitest` for tests.

## `api/src/config.ts`

```ts
export interface ApiConfig {
  secretKey: string
  allowedPolicyIds: Set<string>
  packageId: string
}

function requireEnv(name: string): string {
  const v = process.env[name]
  if (!v) throw new Error(`Missing ${name} environment variable`)
  return v
}

export function readApiConfig(): ApiConfig {
  const secretKey = requireEnv('API_SECRET_KEY')
  const rawIds = requireEnv('API_ALLOWED_POLICY_IDS')
  const allowedPolicyIds = new Set(
    rawIds.split(',').map((s) => s.trim()).filter(Boolean),
  )
  if (allowedPolicyIds.size === 0) {
    throw new Error('API_ALLOWED_POLICY_IDS must contain at least one policy ID')
  }
  const packageId = requireEnv('ACTIONFLOW_PACKAGE_ID')
  return { secretKey, allowedPolicyIds, packageId }
}
```

## `api/src/server.ts`

```ts
import Fastify, { type FastifyInstance } from 'fastify'
import { runPolicyCycle } from 'policyloop'
import type { WalrusUploader, PolicyLoopOptions } from 'policyloop'
import type { TransactionSigner } from 'agentrunner'
import type { ScallopConfig } from 'actionflow'
import type { ApiConfig } from './config.js'

export interface ServerDeps {
  config: ApiConfig
  signer: TransactionSigner
  uploader: WalrusUploader
  scallop?: ScallopConfig
  ai?: PolicyLoopOptions['ai']
}

export function buildServer(deps: ServerDeps): FastifyInstance {
  const { config, signer, uploader, scallop, ai } = deps

  const fastify = Fastify({ logger: false })

  // Auth hook — applied to all routes
  fastify.addHook('onRequest', async (request, reply) => {
    const key = request.headers['x-api-key']
    if (key !== config.secretKey) {
      return reply.status(401).send({ error: 'unauthorized' })
    }
  })

  fastify.get('/health', async () => ({ status: 'ok' as const }))

  fastify.get('/version', async () => ({ version: '0.1.0' }))

  fastify.post<{ Params: { id: string } }>('/policies/:id/run-cycle', async (request, reply) => {
    const { id } = request.params
    if (!config.allowedPolicyIds.has(id)) {
      return reply.status(403).send({ error: 'policy_not_allowed', policyId: id })
    }
    const result = await runPolicyCycle({
      policyId: id,
      packageId: config.packageId,
      walrus: { uploader },
      signer,
      scallop,
      ai,
    })
    return result
  })

  return fastify
}
```

## `api/src/server.test.ts`

Tests use `fastify.inject()` — no real HTTP server or network.

`runPolicyCycle` is mocked via `vi.mock('policyloop', ...)`.

**Test cases (minimum 8):**

1. `GET /health` with valid key → 200, body `{ status: 'ok' }`
2. `GET /version` with valid key → 200, body `{ version: '0.1.0' }`
3. `GET /health` with missing `X-Api-Key` header → 401, body `{ error: 'unauthorized' }`
4. `GET /health` with wrong `X-Api-Key` value → 401, body `{ error: 'unauthorized' }`
5. `POST /policies/:id/run-cycle` with valid key + non-allowlisted policy ID → 403, body `{ error: 'policy_not_allowed', policyId: <id> }`
6. `POST /policies/:id/run-cycle` with valid key + allowlisted ID, `runPolicyCycle` returns skipped → 200, response body equals the `PolicyLoopResult`
7. `POST /policies/:id/run-cycle` with valid key + allowlisted ID → `runPolicyCycle` called with correct `policyId`, `packageId`, `walrus.uploader`, and `signer` reference (via `toHaveBeenCalledWith` or `mock.calls`)
8. `POST /policies/:id/run-cycle` when `runPolicyCycle` throws → reply status 500

**Test setup pattern:**

```ts
const TEST_KEY = 'test-secret'
const POLICY_ID = '0x' + 'aa'.repeat(32)
const PACKAGE_ID = '0x' + '11'.repeat(32)

const testConfig: ApiConfig = {
  secretKey: TEST_KEY,
  allowedPolicyIds: new Set([POLICY_ID]),
  packageId: PACKAGE_ID,
}

const mockSigner = { toSuiAddress: vi.fn().mockReturnValue('0xagent'), signTransaction: vi.fn() }
const mockUploader = { uploadJson: vi.fn() }

// Build server once per suite; Fastify inject does not require listen()
const server = buildServer({ config: testConfig, signer: mockSigner, uploader: mockUploader })
```

## `api/bin/server.ts`

```ts
#!/usr/bin/env node
import { loadAgentKeypair, LocalKeypairSigner } from 'agentrunner'
import { readScallopConfig, readAiConfig, readWalrusConfig, WalrusUploaderImpl } from 'policyloop'
import { readApiConfig } from '../src/config.js'
import { buildServer } from '../src/server.js'

async function main() {
  let config
  try {
    config = readApiConfig()
  } catch (err) {
    console.error(err instanceof Error ? err.message : String(err))
    process.exit(1)
  }

  const walrusConfig = readWalrusConfig()
  if (!walrusConfig) {
    console.error('WALRUS_NETWORK is required for the API server')
    process.exit(1)
  }

  const keypair = loadAgentKeypair()
  const signer = new LocalKeypairSigner(keypair)
  const uploader = new WalrusUploaderImpl({ config: walrusConfig, signer: keypair })
  const scallop = readScallopConfig()
  const ai = readAiConfig()

  const PORT = Number(process.env.PORT ?? 3000)
  const HOST = process.env.HOST ?? '127.0.0.1'

  const server = buildServer({ config, signer, uploader, scallop, ai })
  await server.listen({ port: PORT, host: HOST })
  console.log(`API server listening on ${HOST}:${PORT}`)
}

main().catch((err) => {
  console.error('Unexpected error:', err)
  process.exit(1)
})
```

## Environment variables

| Variable | Required | Notes |
|---|---|---|
| `API_SECRET_KEY` | yes | Checked against `X-Api-Key` header |
| `API_ALLOWED_POLICY_IDS` | yes | Comma-separated policy object IDs |
| `ACTIONFLOW_PACKAGE_ID` | yes | Move package address |
| `WALRUS_NETWORK` | yes | `testnet` or `mainnet` |
| `AGENTRUNNER_PRIVATE_KEY` | yes | Signer keypair |
| `PORT` | no | Default 3000 |
| `HOST` | no | Default `127.0.0.1` |
| `SCALLOP_VERSION_OBJECT_ID` | no | Enables Scallop protocol |
| `SCALLOP_MARKET_OBJECT_ID` | no | Enables Scallop protocol |
| `ANTHROPIC_API_KEY` | no | Enables AI strategy; falls back to legacy deterministic mode |

## Response format

All routes return JSON. The `POST /policies/:id/run-cycle` body is the raw `PolicyLoopResult` union:

```ts
| { ok: true; status: 'skipped'; reason: string }
| { ok: false; status: 'upload_failed'; reason: string }
| { ok: true; status: 'succeeded'; digest: string; eventKind: ...; event: ... }
| { ok: false; status: 'validation_failed'; errors: FieldError[] }
| ... (all other RunActionResult variants)
```

HTTP status codes:
- **200** — all outcomes including failed/skipped (the `status` field in the body carries the outcome)
- **401** — missing or wrong API key
- **403** — policy ID not in allowlist
- **500** — unexpected throw from `runPolicyCycle`
